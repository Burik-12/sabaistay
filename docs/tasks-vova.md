# Задачи Вовы: запустить сбор данных

Обновлено 29-07-2026.

Весь код готов и лежит на VPS. Осталось то, что нельзя сделать за тебя: получить ключи,
подтвердить SMS-код, оплатить подписку и назвать реальные группы Facebook.

**Порядок важен.** Telegram бесплатен и даёт данные сразу — это блокер всего остального.
Facebook стоит денег и расширяет охват, но бессмыслен на неработающем пайплайне.

## 1. Telegram-сборщик · ~40 минут · бесплатно · БЛОКЕР

Без этого витрина показывает данные месячной давности, и все остальные работы бесполезны.

**Состояние на 29-07-2026:** venv и systemd-юниты на месте, но `.env` — нетронутый
шаблон: `TG_API_ID=1234567`, `TG_API_HASH=abcdef…`, `TG_PHONE=+66xxxxxxxxx`.
Ключи надо получать с нуля.

### 1.0. Отдельная SIM — не формальность

Сборщик работает как **userbot**: заходит в Telegram полноценным пользователем.
Отсюда два риска, и второй важнее.

*Блокировка аккаунта.* Telegram не любит автоматизацию. Режим у нас щадящий
(5 каналов, пауза 10 с между ними, опрос раз в 5 минут), вероятность невелика — но
если сработает на личном номере, разом теряются личная переписка, рабочие чаты
Right Way и всё остальное. Низкая вероятность, высокая цена.

*Файл сессии на сервере.* `.session` — фактически ключ от аккаунта: кто получит файл,
тот читает переписку и пишет от твоего имени. Двухфакторка не защищает — она нужна
при входе по номеру, а сессия уже авторизована. Держать на сервере доступ ко всей
личной переписке ради парсинга объявлений — плохой размен.

Тайская предоплаченная SIM: 7-Eleven, 50–100 ฿, пять минут. Заведи на неё Telegram,
с неё же получай ключи. Забанят такой аккаунт — потеряешь ровно ничего.
Нюанс: такие SIM «протухают» без пополнения, а Telegram изредка просит подтвердить
номер — раз в пару месяцев клади минималку.

### 1.1. Получить ключи API

С нового аккаунта: <https://my.telegram.org> → вход по номеру → **API development
tools** → создать приложение (App title `sabaistay`, платформа `Other`).
Нужны `api_id` (число) и `api_hash` (32 символа).

### 1.2. Прописать на сервере

```bash
ssh root@rw-vps
nano /home/rw/sabaistay-secrets/.env
```

```ini
TG_API_ID=<число из 1.1>
TG_API_HASH=<хеш из 1.1>
TG_PHONE=+66<номер новой SIM>
```

`Ctrl+O`, `Enter`, `Ctrl+X` — сохранить и выйти.

### 1.1. Подписаться на каналы этим аккаунтом

Список выверен 29-07-2026 по фактическому выхлопу — было 9 каналов, осталось 5.
Подписаться нужно **тем аккаунтом, чей номер в `TG_PHONE`**:

| Канал | Что даёт |
| --- | --- |
| <https://t.me/koh_phangan_rent> | 90% постов — объявления, самый чистый источник |
| <https://t.me/rent_phangan> | ~8к участников, самый объёмный |
| <https://t.me/phangan_rent> | аренда, 31% полезных |
| <https://t.me/adsphangan> | общие объявления, жильё вперемешку |
| <https://t.me/ru_phangan> | под вопросом — проверим на шаге 1.2 |

Убрал из сбора: `arenda_phangan` оказался «АРЕНДА БАЙКОВ ПАНГАН» (3 объявления жилья
из 153 постов, и именно оттуда лезли цены на технику, ломавшие разбор), а
`phangan_homes`, `phangan_longterm`, `phangan_house` — несуществующие или мёртвые.

### 1.2. Авторизоваться

Одна команда, попросит код из SMS (и пароль двухфакторки, если включена):

```bash
ssh root@rw-vps
sudo -u rw env $(grep -v '^#' /home/rw/sabaistay-secrets/.env | xargs) \
    /home/rw/sabaistay/venv/bin/python /home/rw/sabaistay/ingest/telegram_auth.py
```

Скрипт создаст файл сессии (второй раз код спрашивать не будет) и проверит все 5 каналов:
покажет, какие живые, какие не существуют, какие требуют подписки. **Скинь мне этот
отчёт** — почищу список от мёртвых, чтобы сборщик не долбился в пустоту.

### 1.3. Включить сбор

```bash
systemctl enable --now sabaistay-collector.service sabaistay-build.timer
journalctl -u sabaistay-collector -f     # смотреть живые посты, Ctrl+C для выхода
```

### 1.4. Проверить через час

```bash
sudo -u rw /home/rw/sabaistay/venv/bin/python /home/rw/sabaistay/scripts/data_health.py
```

Должно быть «последний пост: сегодня» и ненулевое «свежих за неделю». Витрина обновится
сама: таймер пересобирает страницу и пушит в git, Vercel деплоит.

## 2. Бот SabaiStay · ~15 минут · бесплатно

Даёт три вещи: подписки на поиск, приём объявлений от владельцев через `/add`
и кнопку «следить за поиском» на витрине.

### 2.1. Создать бота

В Telegram напиши **@BotFather** → `/newbot` → имя и username (должен заканчиваться на `bot`,
например `sabaistay_bot`). Получишь токен вида `12345:AAF...`.

### 2.2. Узнать свой user id

Напиши **@userinfobot** — он ответит числом. Это для админских уведомлений.

### 2.3. Прописать и запустить

```bash
nano /home/rw/sabaistay-secrets/.env
```

```ini
SABAISTAY_BOT_TOKEN=<токен от BotFather>
SABAISTAY_ADMIN_IDS=<твой user id>
SABAI_BOT_USERNAME=sabaistay_bot     # БЕЗ @ — от этого зависит кнопка на витрине
SABAI_CONTACT_TG=sabaistay_bot       # куда писать про удаление объявления
```

```bash
systemctl enable --now sabaistay-bot.service
journalctl -u sabaistay-bot -n 30
```

### 2.4. Проверить

Напиши боту `/start` — должен ответить. Потом зайди на сайт, поставь фильтр
(например район + цена) и нажми «🔔 следить за этим поиском»: бот должен сразу
подтвердить подписку с этим фильтром, ничего не переспрашивая.

## 3. Facebook · ~1 час + $29/мес · расширяет охват

Половина объявлений острова живёт в группах Facebook, и это единственный источник,
которого нет у конкурентов-каналов. Но браться за него стоит после того, как Telegram
поехал: иначе платишь за пайплайн, который всё равно не публикует.

### 3.0. Отдельный аккаунт НЕ нужен — в отличие от Telegram

Разница принципиальная. В Telegram сбор идёт **от твоего имени**: userbot логинится
в аккаунт, поэтому и риск бана, и файл сессии на сервере.

Здесь наоборот: группы скрапит **сторонний сервис (Apify) со своих серверов**, читая
публичные страницы. Твой аккаунт Facebook в сборе не участвует вообще — cookies мы
намеренно не задаём (и ради PDPA, и чтобы не собирать данные продавцов). Ни бана,
ни сессии на сервере.

Аккаунт Facebook нужен ровно для одного — **найти группы руками**: без входа
поиск по группам ничего не показывает. Это обычный просмотр в браузере,
никакой автоматизации от твоего имени.

### 3.1. Найти живые группы — **это могу только ты**

Мне поиск по Facebook недоступен: без входа он ничего не отдаёт, а веб-поиск в текущей
сессии не работает. Нужны **3–6 групп** аренды Пхангана.

Как искать: в самом Facebook по запросам `Koh Phangan rent`, `Пханган аренда`,
`Phangan housing`, `Phangan long term rental`. Отбирай по свежести — важно, чтобы посты
шли **каждый день**, а не раз в неделю.

**Группа должна быть ПУБЛИЧНОЙ** — закрытые скрапер не умеет, это ограничение самого
актора. Но определять это на глаз не нужно: Facebook закрыт снаружи наглухо и без входа
не отдаёт даже публичные группы (проверял 29-07-2026 — на все запросы отвечает `Error`).

Поэтому просто собери кандидатов и проверь их одной командой — актор ответит точно:

```bash
sudo -u rw env APIFY_TOKEN=<токен> \
  /home/rw/sabaistay/venv/bin/python /home/rw/sabaistay/ingest/fb_apify.py --probe \
  https://facebook.com/groups/группа1 https://facebook.com/groups/группа2
```

Прогон по 5 постов на группу стоит копейки. По каждой скажет: отдала посты или нет,
сколько из них с текстом, и покажет пару примеров — сразу видно, аренда там или мусор.

Годные добавь в конфиг (или пришли мне список — подставлю):

```bash
nano /home/rw/sabaistay/data/fb_sources.json
```

В `tasks[0].input.startUrls` сейчас стоят **заглушки** — я их выдумал как пример формата,
таких групп может не существовать. Их надо заменить на реальные:

```json
"startUrls": [
  { "url": "https://www.facebook.com/groups/<реальная-группа-1>" },
  { "url": "https://www.facebook.com/groups/<реальная-группа-2>" }
]
```

### 3.2. Оплатить Apify

<https://apify.com> → регистрация → план **Starter $29/мес** (в него входят резидентные
прокси, без них скрапер FB блокируют). Затем **Settings → Integrations → API token**.

По деньгам: сбор из групп стоит от $2.60 за 1000 постов. При 3–6 группах и суточной
частоте расход укладывается в тариф, отдельно доплачивать не придётся.

### 3.3. Прописать токен и включить

```ini
APIFY_TOKEN=<токен из Apify>
SABAI_ALERT_BOT_TOKEN=<токен бота из шага 2.1>
SABAI_ALERT_CHAT_ID=<твой user id>
```

Последние два — куда слать тревогу, если сбор встанет. Можно тот же бот.

```bash
systemctl enable --now sabaistay-fb.timer
systemctl start sabaistay-fb.service      # первый прогон вручную
journalctl -u sabaistay-fb -n 50
```

### 3.4. Проверить качество

В логе смотри строку про долю распознанных объявлений. Если ниже 30% — сборщик сам
пришлёт тревогу: значит формат постов в этих группах отличается от Telegram и парсер
надо подстраивать. Скинь мне лог, доработаю.

Marketplace (`fb_marketplace` в конфиге) намеренно выключен: у актора рейтинг 2.89/5,
и cookies мы не задаём, чтобы не собирать данные продавцов. Включим, если групп окажется мало.

## 4. Домен и аналитика · ~20 минут

Не блокер, но до запуска стоит закрыть.

- Купить домен (Timeweb, там уже есть аккаунт) → привязать к проекту в Vercel.
- Прописать `SABAI_SITE_URL=https://<домен>` — от него зависят canonical, sitemap
  и картинка при отправке ссылки в мессенджер.
- Vercel → Analytics → включить тумблер (код на сайте уже стоит, ждёт включения).
- Vercel → Settings → Security: проверить **Attack Challenge Mode**. Если включён —
  первый заход отдаёт JS-проверку вместо страницы, и поисковики сайт не проиндексируют.
