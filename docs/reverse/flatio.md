# Flatio — разбор для SabaiStay

Дата: 25-10-2026. Смотрели живьём: главная (mobile), выдача Lisbon (mobile + desktop), карта,
фильтры, страница объекта. Всё открыто без логина. Скриншоты: `scratchpad/reverse/flatio-01…06`.
Flatio — ближайший по аудитории: «помесячная аренда для цифровых кочевников», 1–12 мес.

## 1. Карта экранов и путь

```text
Главная: hero «Hand-picked monthly rentals you can trust» + форма «Город / Move in – Move out» + SEARCH
  ├─ TrustScore 4.3 + отзывы гостей каруселью («Fernando C., spent 12 months in Budapest»)
  └─ Подборки: популярные поиски, Top Picks, новые, coliving, блог, «Сдайте жильё бесплатно»
Выдача /s/<город>: список + (по кнопке) карта
  ├─ FILTERS (модалка), сортировка «Recommended»
  ├─ Карточка → Объект /rent/apartment/<id>-<город>?from=&to=
  │     ├─ Бейджи «Verified by guest», «StayProtection + Stay Benefits»
  │     ├─ Ряд фактов-иконок, скорость интернета, удобства, карта, отзывы, политика отмены
  │     └─ Липкий блок: avg. цена/30 дней, даты, расчёт с Service fee, депозит 0 € → Continue → логин → оплата
  └─ ♡ в шапке (избранное)
```

Регистрация — только на «Continue» (бронь) и ♡. Пейволла для просмотра нет.

## 2. Устройство экранов

**Выдача desktop.** Слева список 2 колонки (~840 px), справа **серая заглушка карты с кнопкой
«SHOW MAP»** — Google Maps грузится только по клику (в DOM есть `userInteractionPrompt` →
`initMapOnClick`). Экономия на Maps API и на весе страницы. Сверху справа — плашка-соцдоказательство
«Wow! More than 1171 possible guests were interested in these listings in the last 2 days».

**Выдача mobile.** Шапка fixed, поле «Lisbon · Dates · Guests» + жёлтая квадратная кнопка
фильтров. Заголовок «561 amazing listings are waiting for new guests» (зелёным число).
**Плавающая тёмная пилюля «Map» снизу справа** ↔ «List». В режиме карты внизу fixed-полоса
«1 – 34 out of 561 ›» — пагинация по 34.

**Карточка (очень информативная):**
- лента «Top pick» / «Top pick + 18 % off!» жёлтой полосой над фото;
- фото-карусель, аватар хоста, бейджи защиты;
- «Apartment in Lisbon ★ 4.8 (8)», подзаголовок;
- **факты: «1 bedroom · 32 m² · 📶 862/423 Mbps»** — скорость интернета прямо в карточке;
- **конкретное окно доступности «Nov 21, 2026 – Jan 19, 2027 (59 nights)»** — даже без ввода дат;
- «€50 / night», «€3,363 total»;
- зелёным: **«All utilities included · No deposit»**.

**Фильтры (модалка):** цена за ночь «Total rent incl. all fees»; тип (дом / апартаменты / комната);
спальни сегментом «Doesn't matter / 1+ … 6+»; удобства группами (бельё, кухня, электроника,
здание, «что-то сверху»: сауна, бассейн); уборка; особые (без депозита, с питомцами, для семей,
курение); **скорость интернета: Download / Upload Мбит/с** — отдельный фильтр. Футер:
«Cancel filters» / «Show 561 listings».

**Карта:** Google Maps, белые пилюли-цены «€57», без кластеров (наложение пилюль), нижняя полоса
с пагинацией.

**Объект:** мозаика 1+4, «Show photos»; бейджи; H1; **ряд из 7 плиток-фактов с иконками**
(люди / спальни / ванные / м² / этаж / Wi-Fi / мебель); бирюзовый баннер StayProtection;
секции: скорость интернета, комнаты, удобства, «Where you will live», отзывы, политика отмены,
**Rental length**, **Move-in and move-out**, Stay Benefits, «6 reasons why…», «How Flatio works».
Справа липкий расчёт: «avg. 1 474 € / 30 days, incl. utilities and internet», Move in/out,
«Price for 60 days 2 948 € + Service fee 415 € = 3 363 €», «Refundable deposit 0 €»,
«Payment schedule», кнопка Continue.

**Тех-стек:** серверный рендер (Rails/Hotwire — контроллеры Stimulus `data-controller=…`),
не SPA. Быстро, хорошо для SEO. Карта ленивая.

## 3. Монетизация

- **Хост:** размещение бесплатно, комиссия **5 % (комнаты) / 7,5 % (целиком) + НДС** с каждого платежа.
- **Арендатор:** разовый **сервисный сбор**, процент не публикуют, падает с длиной брони
  (в примере выше 415 € на 2 948 € ≈ 14 %).
- **Без депозита** для броней < 180 дней — главный продающий тезис; дыру закрывает страховка
  AXA (StayProtection: возврат при незаезде + до 7 ночей альтернативы; Stay Benefits —
  ответственность до 20 000 €).
- Ценность формулируют: «No hidden fees. Utilities and Wi-Fi included», «Deposit-free», «Verified».
- Trustpilot 4,3 (795 отзывов, 10 % единиц): хвалят простоту и безопасность платежей; ругают
  отказы карт из ряда стран и слабую поддержку при отменах до заезда.

## 5. Что взять SabaiStay

**Берём:**
- **Скорость интернета как факт и фильтр** — для номадов на Пхангане это критерий №1 вместе
  с районом. Парсить «fiber», «100 Mbps», «3BB/AIS» из текста объявления, показывать 📶.
- **Окно доступности текстом** «с 1 дек, на 3–6 мес.» на карточке без ввода дат.
- **Зелёные «хорошие» факты одной строкой**: «свет по счётчику · без депозита · уборка включена»
  — если в тексте есть.
- **Ряд плиток-фактов с иконками** на странице объекта — у нас это и есть «замена фото».
- **Ленивая карта по кнопке** на desktop или хотя бы ленивые тайлы — экономия и скорость.
- **Плавающая пилюля «Карта ↔ Список»** внизу на мобиле (если не делаем шторку).
- **Блок «Как это работает»** на объекте: «мы собрали из TG-канала X, оригинал ↗, мы не посредник».
- **Сегмент «1+ / 2+ / 3+»** для спален.
- Серверный рендер (у нас уже статический билд) — правильно для SEO, не уходить в тяжёлый SPA.

**Не берём:**
- Бронь, оплату, сервисный сбор, страховку — мы агрегатор, не платформа сделки.
- Соцдоказательство «1171 гость интересовался» — у нас нет честной метрики; выдумывать нельзя.
  Можно честное: «на этой неделе 23 новых объявления».
- «Top pick» без понятного критерия.
