# Kamernet — разбор для SabaiStay

Дата: 25-10-2026. Смотрели живьём: страница объекта (desktop, пришли с RentSlam), выдача
Amsterdam (mobile 390), карта, клик «Save Search» и «Contacteer verhuurder» (оба ведут на
регистрацию, дальше не шли). Цены и отзывы — Trustpilot, условия, сравнения (Findify, Luntero).
Скриншоты: `scratchpad/reverse/kamernet-01…04`. Kamernet — часть HousingAnywhere.

## 1. Карта экранов и путь

```text
Главная / «Housing offers» → Выдача /en/for-rent/properties-<город>
  ├─ [🔔 Save Search] (зелёная) · [Filters (1)] · сегмент Tile | Map · сортировка «Newest first»
  ├─ Плашка «1787 others are looking for a place in Amsterdam so act fast»
  ├─ Карточки «New» … затем блок «Featured top ads» (платные)
  └─ Карточка → Объект /huren/<тип>-<город>/<улица>/<id>
        ├─ Факты: цена (incl. utilities), м², тип, ДОСТУПНО С–ПО, «Viewing possible»
        ├─ Хозяин + «Last seen 24 oct 2026»
        ├─ «Wat je krijgt / Wat je betaalt / Waar je woont (Leaflet+OSM) / Идеальный жилец»
        ├─ «Знай, когда появятся похожие» → подписка
        └─ [Contacteer verhuurder] → логин → PREMIUM-ПЕЙВОЛЛ (без него написать нельзя)
Save Search → «Sign up to get alerts» (Google / email) — регистрация бесплатная
```

## 2. Устройство экранов

**Выдача mobile.** Сверху поле города + тёмная кнопка поиска; ниже **зелёная «Save Search» с
иконкой колокольчика рядом с «Filters (1)»** — подписка на поиск поставлена на уровень фильтров,
это главное действие. Сегмент «Tile | Map». Плашка срочности «1787 others are looking…».
«324 Rental properties in Amsterdam», сортировка «Newest first» по умолчанию.

**Карточка:** фото, бейдж «New», ♡; «Улица, Город»; «92 m² furnished Room»;
**диапазон дат «1 Nov 2026 – 1 May 2027»** или «From 25 Oct 2026»; «€1,050 /month incl. utilities».
После органических — блок «Featured top ads» с бейджем «Top ad» (платное продвижение).

**Карта:** Google Maps, круглые кластеры-счётчики. При переключении на Map слетел город — карта
показала всю Голландию (баг сохранения состояния) — антипример.

**Объект (desktop):** хлебные крошки (SEO), H1-улица, «Gemeubileerd appartement te huur ·
адрес · **4 uur geleden geplaatst**», «Delen / Bewaren». Слева фото, справа **карточка фактов
с иконками**: € 2.200/maand incl. vaste lasten · 150 m² · **Beschikbaar vanaf 18 jan tot 5 may** ·
Bezichtiging mogelijk. Ниже хозяин «Particuliere verhuurder · Laatst gezien op 24 oct».
Секции: «Что получаешь» (приватная кухня/ванная, интернет, энергокласс, соседи, питомцы),
«Что платишь» (аренда / залог €100 / доп. расходы), «Где живёшь» (**Leaflet + OSM**),
«**Идеальный жилец хозяина**» (кол-во, возраст, пол, занятость, языки, срок) — фильтр отказа
заранее. Внизу CTA «Weet wanneer er soortgelijke woningen online komen» → подписка, и «Похожие».

**Регистрация по точке входа:** URL несёт `source=search_alert`, экран говорит «Sign up to get
alerts — Know when interesting listings are posted and be the first to react» — текст подстроен
под действие, которое человек хотел сделать.

## 3. Монетизация

**Модель «смотреть бесплатно — писать за деньги» (жёсткий пейволл на контакт).**

| План (арендатор) | Цена | Продление |
|---|---|---|
| 2 недели | ~€29 | авто |
| 4 недели | €38–39 | авто (помесячно) |
| 12 недель | €75–79 | авто, дальше «лояльная» ставка |
| 6 месяцев | €98 | без продления |

(Цифры расходятся между источниками на €1–4 — Kamernet их меняет; актуальные только на чекауте.)

- **Бесплатно:** аккаунт, поиск, фильтры, email-алерты, сохранённые поиски, профиль (хозяин
  может написать сам).
- **Платно:** отклик на объявление. Исключение — объявления с «Better reach» (хозяин доплатил,
  чтобы ему могли писать бесплатные пользователи).
- **Хозяину:** размещение бесплатно; платно — «Better reach», **Top ad** (продвижение в ленте).
- **Нет триала.** Отказ в 14 дней — частичный возврат за неиспользованное; после автопродления
  возврата нет. Напоминание за 3 дня до списания (по словам компании).

**Отзывы:** Trustpilot 3,2 (3 127 отзывов; **21 % единиц**). Жалобы: «платишь €37/мес, чтобы
писать в чёрную дыру» — хозяева не отвечают, т.к. откликов сотни; **неожиданные автопродления и
отказы в возврате**; скамеры; поддержка-бот. Хвалят: удобно, быстрая верификация, «лучшая из
плохих». Модель работает финансово, но бьёт по доверию.

## 4. iPhone-приложение

## 5. Что взять SabaiStay

**Берём:**
- **Кнопку «🔔 Следить за поиском» рядом с «Фильтрами»** — на мобиле на одном уровне, яркая.
- **Сортировку «сначала новые» по умолчанию** и бейдж «New» / «4 ч назад».
- **Диапазон доступности «с 1 дек по 1 мая»** на карточке — для зимовщиков ключевое.
- **«Цена включает коммуналку / свет отдельно»** — явно, рядом с ценой.
- **Блок «Идеальный жилец» → у нас «Условия хозяина»**: мин. срок, питомцы, депозит, только
  долгосрочно, «без вечеринок» — парсится из текста, экономит людям пустые сообщения.
- **«Хозяин последний раз активен»** → наш аналог: «пост повторён 3 раза за 2 недели» /
  «последний раз видели в канале 2 дня назад» — сигнал, что объявление живо.
- **CTA подписки на странице объекта** «Сообщить о похожих» — подписка с предзаполненными
  параметрами этого объекта (район, цена ±20 %, спальни).
- **Текст регистрации/подключения бота по точке входа**.
- **Leaflet + OSM** для карты на странице объекта — бесплатно и достаточно.

**Не берём:**
- **Плату за контакт** — у нас контакт в чужом Telegram, перекрыть его нельзя и не нужно;
  к тому же это главный источник ненависти на Trustpilot.
- **Тихое автопродление** — если будет подписка: напоминание за 3 дня в боте + отмена одной
  командой `/stop`.
- Плашку «1787 человек ищут — торопись» без реальных данных.
- Терять город при переключении на карту — состояние держать в URL.
