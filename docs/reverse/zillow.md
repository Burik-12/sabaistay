# Zillow (Rentals) — разбор для SabaiStay

Дата: 25-10-2026. Смотрели desktop-выдачу аренды Austin TX. **Ограничения:** клик «Save search»
открыл попап логина, который заблокирован антиботом PerimeterX («Access denied»); страница объекта
открылась, но под капчей «Нажмите и удерживайте»; мобильная версия 390 px сразу отдала 403.
Остальное — по публичным источникам и App Store. Скриншоты: `scratchpad/reverse/zillow-01…03`.

## 1. Карта экранов и путь

```text
Главная (Buy / Rent / Sell…)
  └─ Выдача Rent: левая вертикальная навигация (Search / Updates / Favorites / Plan / Inbox)
       ├─ Строка фильтров: поиск · For rent ▾ · Price ▾ · Beds & baths ▾ · Property type ▾ · Filters ▾ · [Save search]
       ├─ Карта слева (~48 %) + список справа
       └─ Карточка → объект открывается ОВЕРЛЕЕМ поверх выдачи («← Back to search»)
             ├─ Save / Share / More
             ├─ Pricing & availability, Cost calculator, Facts & policies, Travel times, школы
             └─ Request a tour / Request to apply → логин → заявка ($35 платит арендатор)
  Updates (лента изменений по сохранённым поискам) · Favorites · Inbox (переписка)
```

## 2. Устройство экранов

**Выдача desktop.** В отличие от Airbnb, **карта слева, список справа** (2 колонки карточек).
Над картой — плашка «500 of 23 864 homes» (честно: карта рисует не всё), чипы «Schools ▾» и
«Remove Boundary ×» — выдача ограничена полигоном города, его можно снять. Справа вверху —
заголовок, «23 864 rentals available», «Sort: Recommended ▾».

**Карта.** Google Maps, **кластеры-пилюли «24 units / 62 units»** (по зданиям) + отдельные иконки
домиков. Синяя граница города. Кнопка «Map ▾» переключает слои. Полигон рисования (draw) — в
мобильном приложении.

**Карточка.** Фото с бейджами-акциями сверху («4 Months Free», «10 Weeks Free», «Sparkling pool»,
«Sponsored»), ♡; цена «$825+» + синий значок «Total monthly price» (проверенная полная цена);
адрес; **ряд мини-цен по планировкам** («$825+ 1bd | $1,288+ 2bd»); иногда строка-инсайт
«Lounge • Rare in Austin (15%)»; **крупная синяя CTA «Check availability»** прямо на карточке.

**Виртуализация списка:** в DOM 117 `li`, но только 9 содержат реальную карточку — остальные
пустые заглушки нужной высоты, наполняются при прокрутке. Это как раз приём для длинных лент.

**Страница объекта** — оверлей поверх выдачи (сохраняется скролл и фильтры, URL меняется).
Фото-мозаика 1+4; бейдж «Verified ✓»; плашки-факты с иконками «Apartment building / 1-2 beds /
Pet-friendly»; секции: Pricing & availability («See what you'll pay» + **Cost calculator** —
аренда, сборы, депозит), What's special, Facts & policies, Amenities, Travel times (время до
точки), Getting around (walk/transit score), школы, FAQ, похожие. Справа липкий блок «Request a
tour / Request to apply».

**Левая навигация «Updates»** — отдельная лента «что изменилось в моих поисках» (новые, снижение
цены, снято с рынка). Это продуктовый приём удержания, а не просто уведомления.

## 3. Монетизация

Для арендатора поиск бесплатный. Деньги:
- **Заявка $35** с арендатора (скрининг кредита/фона входит), арендодателю бесплатно.
- **Размещение для арендодателей бесплатно** (с 2022); **Premium-апгрейд ~$39.99 за объявление
  на 90 дней** — выше в выдаче, трекинговый номер, аналитика лидов.
- **Спонсорские карточки** («Sponsored») от управляющих компаний — платное продвижение в ленте,
  плюс бейджи-акции («10 Weeks Free») — тоже маркетинговый инструмент управляющих.
- Оплата аренды через Zillow: ACH бесплатно, карта 2,95 %.
- Жалобы (App Store): 80 % управляющих не отвечают, фильтр по питомцам врёт, нельзя пожаловаться
  на «молчуна».

## 4. iPhone-приложение

4,8★ (7,2 млн оценок), Editors' Choice. Ключевое отличие — **пуши по сохранённым поискам:
«новое», «ушло в pending», «упала цена»**; рисование области пальцем; совместные коллекции с
партнёром/соседом (теги и комментарии); 3D-туры. На сайте то же уведомление — только email.

## 5. Что взять SabaiStay

**Берём:**
- **Ленту «Обновления»** по подписке: «новое», «подешевело», «снято/не отвечает» — у нас это
  можно считать из парсинга (одно и то же объявление перепощено дешевле, пропало из канала).
  Это ценнее простого пуша и годится для платного уровня.
- **Бейдж «Total monthly price»** → наш аналог «цена за месяц» / «цена посуточно ×30, оценка» —
  честно метить, откуда цифра.
- **Строку-инсайт на карточке** «Бассейн · редкость в Шри Тану (12 %)» и «−24 % к медиане района».
  У нас есть бенчмарк, это заменяет фото как «крючок».
- **Плашку «показано 300 из 1 200 на карте»** — честность про ограничения.
- **Кластеры с числом** на дальнем зуме, пилюли-цены на ближнем.
- **Объект оверлеем поверх выдачи** (desktop) — не теряется скролл и фильтры.
- **Виртуализацию списка** заглушками фиксированной высоты.
- **Cost calculator** в мини-формате: «аренда + свет ~8 ฿/кВт + вода + депозит» → «≈ в месяц».
- **Совместное избранное** (для пар/компаний зимовщиков) — позже, в iOS.

**Не берём:**
- CTA «Check availability» на карточке — нашим действием будет «Открыть в Telegram ↗».
- Заявки с оплатой, скрининг, оплату аренды — мы не посредник.
- Спонсорские карточки без маркировки — если будут, то с явной меткой «Реклама».
- Агрессивный антибот: для нас важно обратное — открытость для поисковиков (SEO по районам).
