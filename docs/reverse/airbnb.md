# Airbnb — разбор для SabaiStay

Дата: 25-10-2026. Смотрели живьём через Playwright: выдача «Ко Пханган, помесячно, 1 дек – 1 мар»,
фильтры, страница объекта, мобильная выдача 390 px, «сердечко» без логина.
Скриншоты: `scratchpad/reverse/airbnb-01…05`.

## 1. Карта экранов и путь

```text
Главная (поиск «Где / Когда / Кто»)
  └─ Выдача: список слева + карта справа (desktop) / карта сверху + шторка со списком (mobile)
       ├─ Чипы-удобства в ряд + кнопка «Фильтры» → модалка
       ├─ Карточка → Страница объекта (открывается в новой вкладке на desktop)
       │     ├─ Фото-мозаика, факты, «Плюсы жилья», удобства, календарь, отзывы, хозяин, карта района
       │     └─ Липкий блок цены справа → «Забронировать» → логин → оплата
       └─ ♡ на карточке → сразу шторка «Войдите или зарегистрируйтесь»
```

- **Регистрация** выпрыгивает только на действии (♡, бронь, сообщение), просмотр полностью открыт.
- **Пейволла нет** — деньги берутся комиссией с брони (с 2026 года 15,5 % с хозяина, гостевой сбор
  убран; см. ниже).

## 2. Устройство экранов

**Выдача, desktop 1440.** Две колонки ~50/50: слева сетка 2×N карточек, справа Google Maps
(у Airbnb свой стиль карты через `map_ids`). Шапка `sticky`, карта — `sticky` до футера.
24 карточки на страницу, пагинация внизу (не бесконечный скролл).
Над списком — заголовок «653 варианта жилья» и плашка «В цену входят все сборы».

**Маркеры на карте = ценники-пилюли** (белая пилюля, цена за месяц). Кластеров нет: при
перекрытии часть пилюль сворачивается в точки (видно серые «овалы» без цены). Ховер по карточке
подсвечивает пилюлю (тёмная заливка), клик по пилюле — мини-карточка над картой.

**Карточка:** фото-карусель 1:1 с точками (листается стрелками на ховере), ♡ в углу,
бейдж «Суперхозяин». Под фото 4 строки: тип+район / название / «1 спальня · 1 кровать · 1 ванная» /
цена «зачёркнутая → итоговая помесячно». Ниже мелкие теги «Месячная скидка», «Бесплатная отмена».
Рейтинг справа в первой строке, у новых — «★ Новое».

**Фильтры (модалка по центру, ~570 px):**
1. «Рекомендуем вам» — 4 плитки-иконки (большие тап-зоны, контекстные по городу).
2. Тип размещения — сегмент «Любой / Комната / Жильё целиком».
3. **Цена — гистограмма распределения + двойной слайдер**, подпись «Цена за месяц, включая все сборы».
4. Комнаты и кровати — степперы «Неважно −/+».
5. Удобства — чипы с «Развернуть».
6. Возможности бронирования, тип жилья, доступная среда, язык хозяина — свёрнутые аккордеоны.
7. **Липкий футер «Очистить всё» / «Показать 653 варианта»** — счётчик живой, пересчитывается
   при каждом изменении.

**Мобильная выдача 390:** карта на весь экран сверху (fixed), **список — bottom sheet** с ручкой
(«grabber»), стартует на ~45 % высоты, тянется вверх до полного списка. Сверху fixed-пилюля
поиска «Ko Pha ngan: жильё · даты · кто едет» + иконка фильтров; ряд чипов-удобств под ней.
Внизу таб-бар «Поиск / Вишлисты / Войти».

**Страница объекта:** H1 + «Поделиться / Сохранить» справа; мозаика 1+4 фото, «Показать все фото»;
факты строкой «2 гостя · 1 спальня · 1 кровать · 1 ванная»; рейтинг; хозяин; «Плюсы жилья»
(3 буллета с иконками); описание (авто-перевод, при первом заходе модалка «Перевод включён»);
удобства; календарь; отзывы; карта района; «Важная информация». Справа **липкий блок брони**
(цена, даты, кнопка). На мобиле этот блок превращается в fixed-полосу снизу «цена + Забронировать».

**Микровзаимодействия:** карусель фото сдвигом; ♡ — «пульс» при нажатии; модалки — подъём снизу
с затемнением; на мобиле шторка тянется с инерцией и «прилипает» к 3 позициям; перемещение карты →
список перезапрашивается с шиммер-скелетонами карточек (серые блоки).

**Тех-приёмы:** Google Maps JS (v3), CSS-in-JS атомарные классы, `position: sticky` для шапки/карты,
`dialog` для модалок. Валюта и язык — из гео (нам показало донги, т.к. IP во Вьетнаме) — это
раздражает; явный выбор валюты важен.

## 3. Монетизация

- Для гостя — бесплатно, никаких подписок. С 2026 года **одна комиссия 15,5 % с хозяина**
  (вне ЕЭЗ — с 15.09.2026), гостевой сервисный сбор убран; хосты закладывают её в цену.
  Раньше для 28+ ночей гостевой сбор был ниже — теперь этого «смягчения» нет.
- Около 20 % ночей — в бронированиях от 28 ночей (по данным Airbnb в пересказе отраслевых блогов).
- Ценность формулируют через «В цену входят все сборы» и «Месячная скидка» (зачёркнутая цена).
- Жалобы: высокие цены месячных относительно локального рынка (на Пхангане ~20–35 млн донгов ≈
  27–48 тыс. ฿/мес. — выше, чем в TG-группах), поддержка, штрафы хостам.

## 4. iPhone-приложение

4,8★ (703 тыс. оценок), Editors' Choice. Отличия от сайта: вкладка «Поездки» с офлайн-доступом
(коды, инструкции), чат с хозяином и всеми участниками поездки, пуши. Поиск тот же: карта +
шторка, таб-бар «Поиск / Вишлисты / Поездки / Сообщения / Профиль». Вишлисты — общие, ими
делятся.

## 5. Что взять SabaiStay

**Берём:**
- **Мобильный паттерн «карта сверху + шторка-список с 3 положениями»** — лучший для острова,
  где район = главный критерий. В iOS это родной `sheet` с detents (`.medium`, `.large`).
- **Пилюли-ценники на карте** вместо точек: у нас нет фото, поэтому цена на карте — главная
  визуальная информация. Сокращать «25k», не «25 000 ฿».
- **Гистограмма цен над слайдером** + подпись «за месяц». Данных у нас хватает.
- **Живой счётчик в кнопке фильтров** «Показать 37 вариантов» и «Очистить всё».
- **Факты одной строкой через «·»**: «дом · 2 сп · 1 ванная · 1,2 км до пирса».
- Регистрация только на действии (♡, подписка), просмотр полностью открыт.
- Явный переключатель валюты (฿ / $ / ₽) — у Airbnb авто-гео бесит.
- На iOS: таб-бар «Поиск / Избранное / Подписки / Профиль».

**Не берём:**
- Карусель фото, мозаику, рейтинги, «Суперхозяина» — у нас этих данных нет и не будет.
- Пагинацию по 24 — для 150–300 объявлений проще один список с виртуализацией.
- Авто-перевод модалкой — достаточно тихой пометки «переведено, оригинал ↗».
- Модель «бронь + комиссия»: мы не посредник, ссылка ведёт к первоисточнику.
